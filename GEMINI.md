# Panda HVAC Engineering Platform - Core Vision

This project is a professional HVAC engineering platform designed to help technicians produce accurate, documented, and defensible engineering decisions.

## Not a:
- Proposal generator.
- Generic blueprint viewer.
- Consumer HVAC calculator.

## Primary Objectives
- Save technician time.
- Improve engineering accuracy.
- Increase homeowner trust.
- Create a documented design process.
- Reduce guesswork.

## Core Workflow
`Blueprint` → `Verified Takeoff` → `Manual J` → `Manual D` → `Equipment Selection` → `Proposal` → `Report`

## Engineering Principles
- **Verified data is the source of truth.**
- AI may suggest; technicians verify.
- Manual J must be based on verified inputs.
- Manual D must be based on verified airflow requirements.
- Reports should explain decisions, not just display results.

## Product Philosophy
The goal is to show homeowners: **"Here is how we arrived at this recommendation."**

Every feature should support:
- Accuracy
- Reliability
- Traceability
- Verification
- Trust

## Avoid
- Large refactors.
- Unnecessary UI redesigns.
- Hiding engineering controls.
- Replacing verified workflows with AI automation.

## Preferred Development Method
- One improvement.
- One test.
- One commit.
- Protect working systems.
- Improve engineering confidence.
- Build toward a professional HVAC design platform.
